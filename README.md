# AzerothTracker

A companion app for **World of Warcraft: Forever** in the style of AlecaFrame. It runs as a
separate window on a second monitor (Windows) and reads the data that the AzerothTracker
addon collects in game.

## What it does – in short

AzerothTracker is a **personal tracker for your own characters**. It shows what your alts have
(professions, recipes, materials, gold, currencies, and which of your characters holds an item –
in which bags or bank) in a separate window on a second monitor. It gives no advantage in combat or gameplay – it is a notebook that fills itself in.

**How it works**

1. The **addon** (inside the game) reads your own character through the official WoW addon API:
   level and class, professions and skill, learned recipes, bags, bank (when you open it), gold
   and currencies. It writes this to its SavedVariables file – a normal text file the game
   saves to disk on `/reload`, logout or character switch.
2. The **app** (outside the game) reads that file from your WoW folder and shows the data.
   It never touches the game itself.

**What it does NOT do (fair-play rules we keep)**

- It never reads or changes the game's memory and never modifies game files.
- It never presses keys, clicks or automates anything in the game (no botting).
- It never uses or calculates combat data (no rotations, timers, target marking or similar).
- It never collects data about other players – only your own characters on your account.
- The addon is free, open source, has no ads and asks for no donations in game
  (Blizzard's addon policy).

**Your data**

- Everything stays on your computer. There is no account, no telemetry and no upload.
- The only network request the app makes is downloading the public game-data pack
  (recipes, item names) from this repository's `data-latest` release. Links to Wowhead open in
  your browser only when you click them.

## Modules

The window has three columns: **characters** on the left (level, gold, currencies, last seen,
totals), **bubbles** in the middle (a quick summary each; click opens the full view) and
**item search** on the right (hidden under 🔍 on narrow windows).

- **Professions** bubble – skill per profession and what can be learned; full view with recipes,
  difficulty and materials across all characters' bags and banks.
- **Item search** – "which of my characters has this item?" Searches the bags and banks of all
  your characters on the account (and the account bank), e.g. `Peacebloom 47 = Brakk bags 15 +
  Thrall bags 4 + Thrall bank 8 + account bank 20`. It does not show where an item drops or is
  sold in the game world – use Wowhead for that.

## Development

```bash
cd app
npm install
npm run dev        # start the app
npm test           # tests (Vitest)
npm run typecheck
```

Tests run automatically in GitHub Actions on every push (dependencies are pinned in
`app/package-lock.json`, regenerated by the Lockfile workflow when `package.json` changes).

## Releases and previews

- **App:** pushing a `v*` tag builds the Windows app (`AzerothTracker-<version>.exe`) and the
  addon zip and publishes them as a GitHub Release. Every push to a `feat/**` branch builds the
  same files as a downloadable **windows-preview** artifact on the Actions run page.
- **Game data:** static data lives in `data/` (`items.json`, `professions/*.json`). Pushing a
  change to `main` validates it and publishes `data-pack.json` to the `data-latest` release. The
  app checks for a newer pack at startup and switches to it silently; it always ships a bundled
  copy, so it works offline. The status bar shows the data version (e.g. `Data v12`).
- **Demo mode:** the setup screen has *Try with demo data* to explore the app without the game.

## Product rules

- No Windows/OS notifications – anything that needs attention is shown inside the app window.
- Wowhead is used for manual checks and outbound links only (no automated scraping).
- Everything is in English.
