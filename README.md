# AzerothTracker

A companion app for **World of Warcraft: Forever** in the style of AlecaFrame. It runs as a
separate window on a second monitor (Windows) and reads the data that the AzerothTracker
addon collects in game.

- Design: [`docs/specs/2026-11-01-azerothtracker-design.md`](docs/specs/2026-11-01-azerothtracker-design.md)
- Plan: [`docs/plans/2026-11-01-azerothtracker-v1.md`](docs/plans/2026-11-01-azerothtracker-v1.md)

## Modules

- **Professions** – known / learnable recipes with difficulty, materials across all characters' bags and banks.
- **Alts** – find any item across all characters ("where is my item?"), gold and currencies per character with totals.

## Layout

```
addon/AzerothTracker/   in-game addon
app/                    Electron app
data/                   static game data (JSON)
```

## Development

```bash
cd app
npm install
npm run dev        # start the app
npm test           # tests (Vitest)
npm run typecheck
```

Tests run automatically in GitHub Actions on every push (dependencies are pinned in
`app/package-lock.json`, regenerated by the Lockfile workflow when `package.json` changes).

## Releases and previews

- **App:** pushing a `v*` tag builds the Windows app (`AzerothTracker-<version>.exe`) and the
  addon zip and publishes them as a GitHub Release. Every push to a `feat/**` branch builds the
  same files as a downloadable **windows-preview** artifact on the Actions run page.
- **Game data:** static data lives in `data/` (`items.json`, `professions/*.json`). Pushing a
  change to `main` validates it and publishes `data-pack.json` to the `data-latest` release. The
  app checks for a newer pack at startup and switches to it silently; it always ships a bundled
  copy, so it works offline. The status bar shows the data version (e.g. `Data v12`).
- **Demo mode:** the setup screen has *Try with demo data* to explore the app without the game.

## Product rules

- No Windows/OS notifications – anything that needs attention is shown inside the app window.
- Wowhead is used for manual checks and outbound links only (no automated scraping).
- Everything is in English.
