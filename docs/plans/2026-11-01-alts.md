# AzerothTracker Alts Module Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the Alts tab: item search across characters plus gold and currencies per character.

**Architecture:** Addon writes money and currencies (schema 3); normalizer maps them onto `Character`; pure helpers in `app/src/shared/alts.ts` (search, totals, currency columns) reuse a source builder extracted from `materials.ts`; `AltsView` renders search + table and is registered in `modules.ts`.

**Tech Stack:** unchanged.

**Spec:** `docs/specs/2026-11-01-alts-design.md`

## Global Constraints

- No OS notifications; English copy exactly as in the spec.
- `schemaVersion = 3`; app accepts only 3; higher → existing "addon is newer" message.
- Search: min 2 chars, case-insensitive substring, owned items only, sorted by name, max 50.
- Tests run in GitHub Actions; each task RED push then GREEN push.

## Review Focus

1. Item known only by the addon (not in the data pack) → still searchable. Test in Task 2.
2. Character without money data among others → `–` and excluded from the total. Test in Task 3.
3. Query with regex characters (e.g. `[`) → treated literally, no crash. Test in Task 2.
4. Currency only one character has → column shown, other characters `–`. Test in Task 3.
5. 0 copper → `0c`, not empty. Test in Task 3.
